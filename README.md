# 🐈‍⬛ About Me

Hey, I'm Jeevi! I'm a **Technical Solutions Engineer at Bright Data** and a **Computer Science & Game Design graduate from UC Santa Cruz**, currently pursuing my **M.S. in Computer Science and Engineering**.

I work mostly on **backend systems, APIs, web data pipelines, and production debugging**. Outside of work, I like building things that people can actually use, whether that's a full-stack web app or a multiplayer game.

- Built **Body & Soul**, a 2v2 multiplayer MOBA in Unity/C# with Photon networking
- Built **SlugRush**, a real-time UCSC gym crowd tracker used by **5,000+ students**
- Usually building with **C++, C#, Python, JavaScript/TypeScript, Node.js, and React**

Outside of coding, you'll usually find me at the gym, playing basketball, or gaming with friends.
